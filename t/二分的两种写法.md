有两种写法。建议使用的带 ans 写法，本质上 l~r 为搜索区间，
需要将搜索区间全部处理（长度为 0）：
```cpp
int l = __, r = __, ans = -1;
while (l <= r) { // 总是 <=
    int mid = (l + r) / 2; // 总是 / 2
    if (mid 满足条件）{
        ans = mid;
        r = mid - 1; // 总是带 +-1，也可能是 l = mid + 1
    } else {
        l = mid + 1; // 总是带 +-1
    }
}
答案为 ans;
```

第二种写法，本质上 l~r 为合法区间，需要缩小合法区间长度为 1.
该写法有很多细节，考题有时候会考，但不建议写
```cpp
int l = __, r = __; // 不带 ans
while (l < r) { // 总是 <
    int mid = (l + r) / 2 或者 (l + r + 1) / 2;
    // 当下方为 r = mid 时，必须使用 (l + r) / 2
    // 当下方为 l = mid 时，必须使用 (l + r + 1) / 2.
    // 举例说明：若 l = 3, r = 4，则如果 mid = 3，则执行 l = mid 就会死循环
    // 因此，是否 + 1 取决于要改变 l 还是改变 r.
    if (mid满足条件) {
        r = mid; // 这是找最小可行解。满足条件就不会删除 mid 本身. 找最大可行解时 l = mid
    } else {
        l = mid + 1; // 不满足条件要删除 mid 本身. 可能是 r = mid - 1
    }
}
答案为 l;
```
